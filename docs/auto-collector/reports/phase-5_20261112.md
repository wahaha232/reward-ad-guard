# 階段 5 報告：介面與收尾（2026-11-12）

## 做了什麼

- Compose 新頁籤「自動收取」：App 勾選（BitWalk／AHEALTH／WALK EARN／HAHAGO）、上限（0＝App 預設）、乾跑開關（預設開）、開始／暫停／繼續／結束、狀態（App、最後動作、已收獎勵／廣告／點擊）、最近 50 筆動作。
- `CollectorController` 單例：process 級 coroutine scope，離開 App 或轉屏不會中斷；同一時間只允許一個 job；與除錯入口共用同一個 `CollectorEnvironment`。
- 常駐通知：執行中顯示 App 與進度，附暫停／繼續／結束；`CollectorActionReceiver`（exported=false）。
- 執行紀錄（階段 2 完成，階段 5 驗收）：每次執行一個資料夾，含 `events.jsonl`、`summary.json`、`console.log`、`shots/`；summary 有版本與 `BuildConfig.GIT_HASH`。
- README 增加「Auto collect (opt-in)」章節，並修正「不注入手勢」的描述（守衛本體不注入；自動收取才會）。
