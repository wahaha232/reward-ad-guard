## 找到的問題

1. **LINE 散步趣掃描兩次都沒掃完**：找不到首頁、步數、時間這幾個分頁。很可能是 LINE 停在「精選 › 問卷調查」頁（昨天 17:05 就停在那裡），掃描不會先切回「集點」分頁。抽抽樂已經有「先按集點再找」的處理，散步趣的掃描和收取還沒有。
2. **抽抽樂掃描找不到抽獎頁時，誤報「0 次」**：應該標成「沒掃完」，否則會被當成「已抽完」。
3. **AHEALTH 00:10 找不到「步行」分頁**：當時還不是睡眠畫面。可能是首頁還沒載入完成就去找分頁，需要再觀察。
4. **早上幾輪收取都被打斷**：被使用者操作打斷（切 App、鎖屏）。這是正常的保護行為，不是錯誤。但用電腦指令開的收取沒有「繼續」按鈕，暫停後只能重開。
5. **InMobi 廣告最容易卡住**：主要靠「重開 App」解決，每次大約浪費 2 分鐘。

## 建議

1. LINE 散步趣的掃描和收取在找不到分頁時，先按底部的「集點」再找，做法和抽抽樂一樣。
2. 抽抽樂掃描找不到抽獎頁時，結果標成「沒掃完」。
3. InMobi 廣告逾時改短（例如 60 秒沒進展就直接重開），每次可省下約 1 分鐘。
4. 用電腦指令開的收取，在 debug 指令加「繼續」，或改從 App 介面開跑，這樣暫停後可以接著跑。
